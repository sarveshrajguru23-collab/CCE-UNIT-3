
# Backup Verification Application Using Binary Trees

## Problem Statement
Develop a backup verification application using binary trees to check whether two backup structures are identical and whether one structure is a subtree of another.

## Objective
- To implement binary trees for representing backup file IDs.
- To check whether two backup structures are identical.
- To verify whether one backup structure is a subtree of another.
- To understand binary tree operations and recursive algorithms.

## Introduction
Backup verification is an important process used to check whether stored data structures match correctly. In this project, backup structures are represented using Binary Search Trees (BSTs), where each node contains a backup file ID.

The application compares two backup trees to determine whether they are identical and checks whether one tree exists as a subtree of the other. This project demonstrates the practical use of binary trees, recursion, and tree traversal in Data Structures.

## Data Structures Used
- **Binary Search Tree (BST):** Stores backup file IDs.
- **Recursion:** Used to compare trees and search for subtrees.
- **Inorder Traversal:** Displays backup IDs in sorted order.
- **Preorder Traversal:** Displays the root node before its children.

## Algorithm
1. Start the program.
2. Read the number of backup IDs for the first structure.
3. Insert the IDs into the first Binary Search Tree.
4. Read the number of backup IDs for the second structure.
5. Insert the IDs into the second Binary Search Tree.
6. Compare both trees recursively to check whether they are identical.
7. Check whether the second tree is a subtree of the first tree.
8. Check whether the first tree is a subtree of the second tree.
9. Display the verification results.
10. Release allocated memory and stop the program.

## Features
- Creates two Binary Search Trees from backup IDs.
- Checks whether two backup structures are identical.
- Detects whether one backup structure is a subtree of another.
- Displays inorder and preorder traversals.
- Uses recursive functions for tree comparison.
- Compatible with the Dev-C++ compiler.

## Sample Input
Backup 1:
5
50 30 70 20 40

Backup 2:

30 20 40

## Sample Output
BACKUP VERIFICATION APPLICATION

Inorder  : 20 30 40 50 70
Preorder : 50 30 20 40 70

Preorder : 30 20 40

VERIFICATION RESULTS

1. Backup 1 and Backup 2 are NOT identical.
2. Backup 2 IS a subtree of Backup 1.
3. Backup 1 is NOT a subtree of Backup 2.

## Applications
- Backup structure verification.
- Comparing hierarchical data.
- Detecting matching sections in tree-based data.
- Learning recursive tree algorithms.

The application successfully compares two backup structures and determines whether they are identical or whether one is a subtree of the other.

This project demonstrates the use of Binary Search Trees for backup verification. It provides practical experience with tree insertion, recursive comparison, subtree detection, and tree traversal using C++.
